\# TP7 - Entorno Gráfico



\## Descripción del Proyecto



Este proyecto implementa un sistema de monitoreo y control basado en Arduino, utilizando Processing como interfaz gráfica.



El sistema lee entradas físicas, controla salidas digitales y permite la interacción en tiempo real entre Arduino y una computadora mediante comunicación serial.



\## Componentes de Hardware



\- Arduino UNO

\- Potenciómetro

\- Pulsador

\- Dos LED

\- Buzzer activo

\- Resistencias

\- Protoboard y cables de conexión



\## Software Utilizado



\- Arduino IDE

\- Processing

\- Comunicación serial a 9600 baudios



\## Funcionalidades



\- Monitoreo en tiempo real de las entradas físicas.

\- Indicadores gráficos para entradas y salidas.

\- Controles virtuales para ambos LED.

\- Modo de alerta de emergencia con LED intermitentes.

\- Control independiente del buzzer.

\- Alarma sonora durante el modo de emergencia.



\## Estructura del Proyecto



\- `Arduino/`: código fuente de Arduino.

\- `Processing/`: interfaz gráfica desarrollada en Processing.



\## Cómo Ejecutar el Proyecto



1\. Conectar el Arduino UNO a la computadora.

2\. Cargar el código de Arduino mediante Arduino IDE.

3\. Cerrar el Monitor Serie.

4\. Abrir el sketch de Processing.

5\. Seleccionar el puerto serial correspondiente.

6\. Ejecutar la interfaz gráfica.
