\# TP7 - Graphical Environment



\## Project Description



This project implements an Arduino-based monitoring and control system using Processing as a graphical interface.



The system reads physical inputs, controls digital outputs, and allows real-time interaction between Arduino and a computer through serial communication.



\## Hardware Components



\- Arduino UNO

\- Potentiometer

\- Push button

\- Two LEDs

\- Active buzzer

\- Resistors

\- Breadboard and jumper wires



\## Software



\- Arduino IDE

\- Processing

\- Serial communication at 9600 baud



\## Features



\- Real-time monitoring of physical inputs.

\- Graphical indicators for inputs and outputs.

\- Virtual controls for both LEDs.

\- Emergency alert mode with flashing LEDs.

\- Independent buzzer control.

\- Audible alarm during emergency mode.



\## Project Structure



\- `Arduino/`: Arduino source code.

\- `Processing/`: Processing graphical interface.



\## How to Run



1\. Connect the Arduino UNO to the computer.

2\. Upload the Arduino code using Arduino IDE.

3\. Close the Serial Monitor.

4\. Open the Processing sketch.

5\. Select the correct serial port.

6\. Run the graphical interface.
